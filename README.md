# MCP Workshop

This repository contains the source for the ContextForge MCP workshop published at https://contextforge-org.github.io/mcp-workshop/.

- `docs/` – MkDocs site with the workshop content

## Running the Workshop Locally

```bash
cd docs
uv sync
uv run mkdocs serve
```
